# Hotel Web Scraper
- This project is aimed at scraping hotels from www.booking.com
- It aims to extract the following details:
  1) Hotel Title
  2) Room type the hotels offer i.e deluxe, superior, standard etc.
  3) Price of each room type
  4) Location of the hotel
- The data can be used by hotel competitors to build a recommender system to get the best prices for their hotel and also come up with better amenities to attract customers.
